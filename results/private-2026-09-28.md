# 私有语料上的结果（2026-09-28，不可复现）

> 这一页只有指标。语料、金标题和逐题结果都不公开，所以**这些数字无法用本仓库复现**，
> 只用来说明这套方法最初是在什么场景下做出来、得出过什么结论。公开语料上的可复现结果见 `results/public/`。

## 场景

- 语料：个人中英混合知识库，约 600 篇中文 Markdown 笔记 + 45 份 PDF + 约 790 条英文原始帖子；切成 9,385 段。
  机密材料在入库前整体排除。
- 金标题 108 道：同义词 14、跨语言（中文规则 → 英文原帖）44、数字出处 50。每题带一段在金标文件里逐字存在的证据串，机器核对 108/108 通过。
- 指标按**文件**计（一篇笔记只算一次），这一点和公开版（按段落计）不同。
- 硬件：Apple M4 / 24GB，BGE-M3 与 bge-reranker-v2-m3 均为 fp16、MPS。

## 其他

- 分段前缀消融：去掉「文档标题 > 小节路径」前缀，Recall@5 0.643 → 0.563，配对 bootstrap 95% 区间 [+0.025, +0.136]。
- 过期内容（39 题，用库里「旧值 → 新值」修正记录按模板出题）：第 1 名就是带旧值文件的比例，关键词 0.179、BM25 0.333、向量 0.308。
- 结论：上线纯向量；混合 + 精排质量打平但慢约 37 倍，损失集中在跨语言题（BM25 噪声挤占精排池，精排又偏好中文复述）。
